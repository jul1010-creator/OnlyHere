# There was no robots.txt at all, so /robots.txt fell through vercel.json's
# catch-all rewrite and every crawler asking for it got the app's HTML shell
# back with a 200. A crawler reading that finds no rules and no sitemap line,
# which is the one place a sitemap gets discovered without being submitted by
# hand. middleware.js has been serving a real /sitemap.xml this whole time and
# nothing on the site pointed at it.

# ── AND THE GUIDES THEMSELVES ─────────────────────────────────────────
# Added 17 Aug 2026. Oliver: "We need to make it strictly forbidden to share the
# guides online" / "or publically rather."
#
# A guide URL is unlisted rather than secret, so it is shareable with the people
# on the trip and should not be indexed as a public page. Search engines are told
# not to crawl them at all, which is a different and stronger thing than the
# noindex meta tag: nothing has to be fetched to be obeyed.
Disallow: /guide/

# ── BUT THE PREVIEW CARD HAS TO KEEP WORKING ──────────────────────────
# Sharing a guide with the people on the trip is allowed and is the point of the
# Share button, and what that share LOOKS like is a card built by middleware.js
# for exactly these crawlers. Facebook's fetcher honours robots.txt, so a blanket
# Disallow: /guide/ would have quietly turned every shared guide into a bare
# link — breaking a feature on purpose while trying to protect it. These groups
# are named so the rule above does not apply to them.
