# Lithuanian, for a native speaker to check

Written by Claude on 1 Oct 2026, when Lithuanian became the fourth interface language. Nobody who speaks Lithuanian has read it yet. Please mark anything that sounds wrong, stiff or too formal, and write the better version in the last column.

Three things to know while reading:

1. The interface speaks to the reader politely (jūs, "Prisijunkite"), and buttons use the infinitive ("Prisijungti"), the way most Lithuanian sites do. Say if the site should sound more casual.
2. Some lines are joined to a number in front of them, like "3" + "dienos". Only one plural form fits there, so 10 and more ("10 dienų") may read wrong. Say which counts look wrong.
3. Names of places, products and partners (Gemlyx Find, Rejseplanen, GetYourGuide) stay as they are on purpose.
